Política de Privacidade Conceitual

Este site é um protótipo educacional. O formulário não envia dados para servidor externo. As informações digitadas são usadas apenas para simular uma interação na própria página.

  • Não há coleta real de dados pessoais nesta versão.
  • Não há cookies de marketing ou rastreamento de terceiros.
  • Não há compartilhamento de dados com empresas externas.
  • Para uso oficial, será necessário criar política real, canal de atendimento ao titular e base legal para tratamento dos dados.
